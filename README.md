# Directorio de Clientes — Custom Visual (Aurum)

Visual de Power BI (pbiviz) para el directorio de clientes: búsqueda
multicampo (RUT, nombre, sector, jerarquía) sobre 16.000+ registros, con
lista virtualizada para que no colapse el navegador.

## Conectar los campos

Al arrastrar el visual al reporte, verás un único rol de datos llamado
"Campos". Arrastra ahí, en el orden que quieras que aparezcan como columnas:
RUT, Nombre, Sector, Jerarquía (y cualquier otro campo del directorio).
